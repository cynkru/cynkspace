  Бэкенд Cynk

Сервисы и библиотеки для работы Cynk.

Этот проект основан на исходном коде [Revolt / Stoat](https://github.com/stoatchat/stoatchat) и развивается как отдельный проект.

Исходный проект распространяется под лицензией GNU Affero General Public License v3.0 (AGPL-3.0). Этот проект сохраняет условия указанной лицензии.

В репозитории могут присутствовать изменения, внесённые при разработке Cynk. Данный сервер может быть не совместим с клиентами Stoat
